Sobre mim

Olá! Sou Julia Sales, formada em Direito e atualmente em transição de carreira para a área de tecnologia, setor pelo qual sou profundamente apaixonada. Adquiri uma base forte com a tríade HTML, CSS e JS, estou agora em nível júnior, cursando uma formação completa que abrange desde o Frontend até o Backend – atualmente focada em React, TypeScript e TailwindCSS. Busco constantemente novos conhecimentos e experiências que possam ampliar minhas habilidades técnicas e criativas.

Sou uma pessoa criativa e detalhista, sempre atenta para que cada projeto desenvolvido seja funcional, esteticamente agradável e totalmente responsivo. Além disso, acredito que a tecnologia oferece liberdade e a possibilidade de acompanhar as mudanças que moldam o futuro.

Fora do mundo do código, adoro teatro, filmes, séries, jogos, viagens, experiências culturais, tais quais visitas a museus, exposições de arte, dentre outros, que também inspiram minha forma de criar.

Habilidades

HTML5

Utilizo HTML5 para estruturar páginas de forma semântica, organizada e acessível. Tenho atenção aos elementos corretos para melhorar SEO, acessibilidade e desempenho, garantindo uma base sólida para qualquer projeto web. Busco sempre aplicar boas práticas e padrões modernos no desenvolvimento.

CSS3

Com CSS3, sou capaz de criar estilos personalizados, responsivos e visualmente atrativos. Trabalho com posicionamento, animações e transições para deixar as interfaces mais fluidas e dinâmicas. Também foco em boas práticas de design, proporcionando uma experiência agradável para o usuário.

JavaScript

Utilizo JavaScript para desenvolvimento de interfaces dinâmicas e interativas em páginas web. Trabalho com manipulação do DOM, eventos, condicionais, loops, lógica de programação, dentre outras, visando desenvolver código organizado e reutilizável, melhorando a experiência do usuário nas aplicações web.

TypeScript

Possuo conhecimentos em TypeScript, utilizando tipagem estática para tornar o código mais seguro e organizado. Trabalho com tipagem de funções, objetos e parâmetros, uso de interfaces, type aliases, unions e generics. Também trabalho com import/export de módulos e configuração do projeto através do tsconfig.

React

Tenho conhecimentos em React, criando projetos com Vite e TypeScript. Trabalho com componentes funcionais, JSX, props (incluindo children), renderização condicional, listas, eventos e diferentes formas de estilização. Utilizo Hooks, Context API e Hooks customizados para gerenciar estado, lógica e compartilhamento de dados.

TailwindCSS

Utilizo TailwindCSS para estilização de interfaces modernas e responsivas, realizando sua instalação e configuração em projetos com Vite e React. Tenho familiaridade com o sistema de espaçamento, classes utilitárias e composição de estilos diretamente no HTML/JSX. O uso do Tailwind me permite criar layouts consistentes, ágeis e visualmente organizados, mantendo produtividade e padrão visual nos projetos.

GitHub

Uso o GitHub para hospedagem, versionamento e compartilhamento de projetos. Trabalho com a criação de repositórios, fluxo de trabalho com Git, organização de código e publicação de projetos, facilitando colaboração e acompanhamento do desenvolvimento.

Git

Utilizo Git para controle de versão e organização do desenvolvimento. Trabalho com commits, branches, resolução de conflitos de merge e acompanhamento do histórico de alterações, garantindo segurança e controle durante a evolução dos projetos.
